# The Golden Fork
The Golden Fork is a fast food restaurant website made for my Web Technologies Project 1. It has branches in Johar Town, Gulshan-e-Ravi and Township, and serves burgers, pizza, shawarma and more. The Assignment 1 has three pages. It uses a brown, champagne and amber colour theme, and every page has its own stylesheet.

# Pages
Home (index.html, home.css)
Menu (menu.html, menu.css) = media 
Reserve (register.html, register.css)
